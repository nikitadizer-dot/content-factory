# Product Brief — Mockup Clothing Design Tool

_Last updated: 2026-07-07_

## Product
- **One-liner**: iOS app that turns clothing designs/sketches into photo-real on-model mockups (studio & street scenes) with AI — no photoshoot, no inventory.
- **App Store / URL**: https://apps.apple.com/us/app/mockup-clothing-design-tool/id6756230463 (seller: Nikita Cheremisinov; free + IAP/Pro subscription; iPad-capable)
- **Landing / TikTok / Instagram**: NONE found as of 2026-07-07 — no official social presence yet (confirmed by WebSearch). Accounts to be created cold.
- **Vertical**: AI design tools for clothing brands / print-on-demand / fashion creators
- **Aha moment**: user uploads a flat design or sketch → seconds later sees it as a photo-real garment on a model in a real scene ("that looks like an actual photoshoot of MY design")
- **Unique angle vs competitors**: mobile-first (phone, not desktop web-tool like Botika/The New Black), instant, cheap vs $500+ photoshoots; covers the full path sketch → AI design → on-model shot

## Audience
- **Target persona**: (1) aspiring/early clothing-brand founders (streetwear, 16–30, "how to start a clothing brand" niche); (2) POD sellers (Etsy / Printify / TikTok Shop); (3) designers making portfolio visuals
- **Geo priority**: US-first (App Store US), then EN-global
- **Super-user signal**: uploads own design (not just AI-generated) and exports multiple scenes

- **Voice (one word)**: enabling ("you can look like a real brand today")
- **Reference account**: @sbhelpers (utility-listicle tone), @itsbetterwithai (wow-demo tone)
